# Sri Sabari — AI/ML Engineer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. For a local development server, open this folder in VS Code and use Live Server, or run:
   - `python -m http.server 8000`
   - Visit `http://localhost:8000`

## Before publishing — personalize these items
- Add your resume PDF at `assets/Sri_Sabari_Resume.pdf` (create the `assets` folder if needed).
- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
- Verify every GitHub repository link and add project-specific repositories/demos where available.
- Add screenshots or demo links for each project if you have them.

## Deploy
You can deploy this static site using GitHub Pages, Netlify, or Vercel. No backend or build step is required.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive dark theme and visual styling
- `script.js` — mobile navigation, smooth scrolling, and reveal animations
